# 🧮 Calculadora Plus

Uma aplicação de terminal desenvolvida em Java para praticar e aprimorar fundamentos de lógica de programação, estruturas de repetição, condicionais e tratamento de fluxo.

---

## 🚀 Funcionalidades

- **Autenticação de Usuário:** Sistema de login interativo.
- **Operações Matemáticas:**
  - Soma (`+`)
  - Subtração (`-`)
  - Multiplicação (`*`)
  - Divisão (`/`) com validação de divisão por zero.
  - Potenciação (`^`)
- **Fluxo Contínuo:** Opção de realizar múltiplas operações na mesma sessão.

---

## 🆕 Atualizações Recentes

14/09/2026
